# 🎌 OTAKU — Anime Streaming

Projeto de uma plataforma de animes desenvolvida para praticar **HTML, CSS e JavaScript**.

O site possui uma interface inspirada em plataformas de streaming, com páginas de animes, episódios, favoritos, login e histórico de reprodução.

## ✨ Funcionalidades

- 🔍 Pesquisa de animes
- 🎴 Cards com informações dos animes
- 📖 Página de detalhes de cada anime
- ▶️ Player simulado de episódios
- ⏭️ Navegação entre episódios
- ❤️ Sistema de favoritos
- 🍿 Continue Assistindo
- 💾 Histórico salvo no navegador com LocalStorage
- 👤 Cadastro e login local
- 🚪 Sistema de logout
- ☰ Menu lateral
- 📱 Layout responsivo para celular e computador

## 🎬 Animes disponíveis

- Naruto
- Solo Leveling
- Bleach
- Demon Slayer
- Jujutsu Kaisen

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 💡 Sobre o projeto

Este projeto foi criado com fins de **estudo e aprendizado de desenvolvimento web**.

O player presente no projeto é apenas uma simulação e o site **não hospeda episódios ou conteúdo audiovisual dos animes**.

Os dados de login, favoritos e histórico são armazenados localmente no navegador utilizando `localStorage`.

> ⚠️ O sistema de login é apenas educacional e não deve ser utilizado para armazenar senhas reais.

## 🚀 Objetivo

O objetivo deste projeto é praticar conceitos como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Criação de layouts responsivos
- Manipulação do DOM com JavaScript
- Eventos e interações
- Parâmetros de URL
- Armazenamento de dados com LocalStorage
- Navegação entre páginas
- Criação de interfaces para desktop e dispositivos móveis

## 📱 Responsividade

O projeto foi desenvolvido para funcionar tanto em computadores quanto em dispositivos móveis.

Em telas menores, a interface é adaptada e utiliza um menu lateral para facilitar a navegação.

## ⚠️ Aviso

Este é um **projeto educacional**.

As imagens e nomes de animes utilizados servem apenas como referência visual para demonstrar o funcionamento da interface.

Nenhum episódio ou conteúdo audiovisual protegido por direitos autorais é hospedado neste projeto.
